Frequently Asked Questions

Everything you need to know about Radix Point.

What is Radix Point?

Radix Point is a free online tools platform designed to make everyday digital tasks easier. It provides tools for image conversion, compression, resizing and PDF creation.

Is Radix Point free?

Yes. The current Radix Point tools are available to use for free.

Do I need to create an account?

No. You can use the available tools without creating an account.

Are my images uploaded to Radix Point?

The current image tools are designed to process selected images directly inside your web browser. Your images are not intentionally uploaded to a Radix Point server by these tools.

Which image formats are supported?

The current tools support common image formats including JPG and PNG.

Can I convert JPG to PNG?

Yes. Use the JPG → PNG tool, select your JPG image and generate the converted PNG file.

Can I convert PNG to JPG?

Yes. Select your PNG image using the PNG → JPG tool and generate a JPG version.

Can I compress an image?

Yes. The Image Compressor allows you to select an image and choose the desired quality before downloading the compressed version.

Can I resize an image?

Yes. The Image Resizer allows you to enter a desired width and height and create a resized image.

Can I create a PDF from images?

Yes. The JPG/PNG → PDF tool can create a PDF from supported images.

Will the quality of my image change?

Some operations can affect image quality. Compression especially may reduce file size by reducing image quality. We recommend checking the downloaded result before using it for important purposes.

Does Radix Point work on mobile phones?

Yes. Radix Point is designed to work on modern smartphones, tablets and computers with a compatible web browser.

Which browsers can I use?

Radix Point is designed for modern browsers such as Chrome, Firefox, Safari, Edge and other browsers that support the required web technologies.

Is Radix Point an AI website?

Radix Point is being developed as a broader digital tools platform. AI-powered tools may be added in the future.

Can I suggest a new tool?

How can I contact Radix Point?

You can contact us by email at radixpoint.co@gmail.com .

Will more tools be added?

Yes. We plan to expand Radix Point with additional useful tools and features over time.
